## Как собрать план заново

Дай агенту `PROMPT.md` и папку `data/` и попроси: «Выполни промпт на этих данных, запиши plan.md». Ключ не показывай. Код не нужен.

1. ✅ Письмо о проблеме, решённой в чате (E06 → C31–C34), — не в «горит», а в «решилось без вас».
2. ✅ Встреча, перенесённая двумя письмами (E09 → E19 → E29), стоит на 14.10.2026 11:00.
3. ✅ «К концу следующей недели» (E33 от 08.10) переведено в 16.10.2026.
4. ✅ Ни одна из 12 рассылок и автоуведомлений не попала в план — проверено скриптом.
5. ✅ У каждого из 24 пунктов есть источник, все 96 ссылок существуют — проверено скриптом.
